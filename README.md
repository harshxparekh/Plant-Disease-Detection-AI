# Plant Disease Detection System – AI/ML

## 📌 About
An AI-powered plant disease detection system that
identifies diseases from leaf images and provides
fertilizer recommendations based on CNN classification.

## 🛠️ Technologies Used
- Python
- Deep Learning
- CNN (Convolutional Neural Network)
- Image Processing

## 🚀 Features
- Detects plant diseases from leaf images
- Classifies disease type using CNN model
- Generates fertilizer recommendations
- Built with real agricultural datasets

## 🎯 Purpose
Built to demonstrate real-world application of
AI and Deep Learning in the agriculture sector.
